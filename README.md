# RUMM 18 изнутри — интерактивный баннер K-TRUCK

Посмотреть: https://sergeyshulgasp.github.io/banner_k-truck/

Мини-экскаватор RUMM 18 в изометрии, нарисованный кодом (SVG) на движке [Anatomy](https://github.com/wheresryan22/anatomy): около 360 деталей. При наведении машина разбирается на 15 узлов. Кнопками можно раздвинуть шасси и повернуть стрелу влево-вправо (геометрия стрелы перестраивается в браузере на каждом кадре). При выборе узла внизу появляется подпись с реальными данными.

| Поворот стрелы | кронштейн на двух вертикальных пальцах и гидроцилиндр поворота |

| Двигатель и насос | Kubota D902: блок, головка, крышка клапанов, вентилятор, маховик, гидронасос, глушитель, воздушный фильтр |
| Радиатор | сердцевина, крышка, расширительный бачок |
| Капот, противовес, баки, место оператора, навес, отвал | — |

Размеры и характеристики взяты со страницы модели на k-truck.ru: масса 1 800 кг, Kubota D902 11,2 кВт, транспортная длина 3 337 мм, ширина 1 100 мм, высота 2 325 мм, глубина копания 2 060 мм, ковш 0,04 м³. Устройство узлов сверено со схемами Rippa R18 на parts.rippa.com: рама с телескопическими балками, гидромотор под крышкой, компоновка моторного отсека. RUMM 18 выпускает HighTop, а не Rippa, поэтому детали упрощены и могут отличаться от реальной машины.

## Структура

```
geometry.mjs        сборка модели, узлы разбора и их смещения (PIECES, STAGGER, SPRING)
parts.mjs           детали-примитивы: призмы, точёные детали, гидроцилиндры, шланги
undercarriage.mjs   ходовая: рама, телескопические балки, гусеницы, катки, ленивец с натяжителем, звёздочка, гидромоторы с крышками, отвал с уширителями
upper.mjs           верх: круг, платформа, распределитель, противовес, Kubota D902, радиатор, баки, место оператора, капот, навес
boom.mjs            кронштейн поворота, стрела, рукоять, тяги ковша, ковш, гидроцилиндры, шланги (с углом поворота)
build.mjs           сборка страницы: расчёт порядка отрисовки, SVG, данные для анимации
live.js             анимация в браузере: пружины разбора, раздвижка шасси, выбор узла, автотур
banner.css          оформление баннера (тёмная тема, оранжевый акцент, Montserrat)
kit/                нужные файлы движка Anatomy (MIT, см. kit/LICENSE-anatomy)
rumm18-banner.html  готовая собранная страница (можно открыть сразу)
hero.html           тёмный первый экран: шапка, заголовок, фото RUMM 18 → при прокрутке чертёж → раздвижка шасси → разбор
index.html          копия hero.html для GitHub Pages
hero.css            стили первого экрана и шапки
```

## Запуск

Нужен Node.js 20.10 или новее. Зависимостей нет, `npm install` не нужен.

```sh
npm run build        # полная сборка: порядок отрисовки считается по всем кадрам разбора, ~3 минуты
npm run build:fast   # быстрая сборка без расчёта порядка, для правок геометрии (детали могут перекрываться неправильно)
```

Результат — `rumm18-banner.html`. Откройте его в браузере. Сборка пишет и `hero.html` (первый экран); для GitHub Pages: `cp hero.html index.html`.

## Как поставить на сайт

Страница самодостаточная: внутри SVG, CSS и скрипт, внешний ресурс только шрифт Montserrat. Есть два варианта:

1. **iframe** на главной, под первым экраном: `<iframe src="/banners/rumm18-banner.html" loading="lazy" ...>`.
2. **Встроить напрямую**: перенести блок `<section class="kt-banner">`, стили из `<style>` и скрипт из `<script type="module">`. CSS движка (`.iso…`) нужен тоже.

Вес страницы около 340 КБ. Подключайте баннер ниже первого экрана с ленивой загрузкой, чтобы он не замедлял загрузку главного элемента страницы (LCP). Шрифт на сайте лучше отдавать со своего сервера (см. инструкцию по Montserrat в отчёте).

## Управление

- **Мышь:** наведение разбирает машину и подсвечивает узел под курсором; уход курсора собирает обратно.
- **Касание:** первое нажатие разбирает, следующие выбирают узел, нажатие на пустое место собирает.
- **Клавиатура:** пробел или Enter — разобрать или собрать, стрелки — следующий узел, S — раздвинуть шасси, R — повернуть стрелу, Escape — собрать.
- **Кнопки:** «Разобрать», «Раздвинуть шасси», «Повернуть стрелу» и список узлов.
- **Автотур:** без действий посетителя баннер сам поворачивает стрелу, раздвигает шасси, разбирает машину и проходит по узлам. Через 9 секунд после последнего действия тур возобновляется.
- **Сниженная анимация:** при `prefers-reduced-motion` анимация не идёт, всё переключается сразу.

## Известные ограничения и что доработать

- **Порядок отрисовки** рассчитан движком по 43 положениям (покой, разбор, промежуточные доли). На отдельных кадрах в середине разбора деталь может на мгновение оказаться не над той соседней. Полный аудит Anatomy с прогоном всех кадров анимации (`node build.mjs --full`) занимает около 10 минут и не проводился.
- **Вес страницы** около 870 КБ (внутри движок для поворота стрелы). Ставьте баннер ниже первого экрана с ленивой загрузкой.
- **Поворот стрелы** перестраивает около 110 деталей за кадр (около 15 мс). На слабых телефонах анимация может идти рывками.
- **Логотип K-TRUCK** в баннер не включён.
